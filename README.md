# 阅见 · Django 本地版

仓库地址：https://github.com/Cindyguokunkun/reading-garden-django

标准 Django Templates 项目。Django 同时负责页面、登录、业务逻辑和 SQLite 数据库；页面交互不依赖 React。

## 初次安装

双击 `setup.bat`。完成后双击 `start.bat`，打开 http://127.0.0.1:8000/。

- 初始用户名：`teacher`
- 初始密码：`reading123`（首次登录后请在 `/admin/` 修改）
- 数据库文件：`db.sqlite3`

手机与电脑连接同一 Wi-Fi 后，在手机访问 `http://电脑局域网IP:8000/`。Windows 防火墙首次询问时允许“专用网络”。

## 四种角色与登录入口（P1）

登录枢纽 `/login/` 提供三个入口：

| 角色 | 入口 | 登录方式 | 能做什么 |
| --- | --- | --- | --- |
| 学生 | `/student/login/` | 免密：选班级 → 点自己名字 | 自助先读后测、看个人记录与排行榜 |
| 家长 | `/parent/login/` | 孩子的邮箱 + 密码（由管理者导入时发放） | 只读查看孩子阅读记录、目标进度、排行榜 |
| 老师 / 管理者 | `/login/staff/` | 账号密码 | 老师管本班；管理者（superuser 或 Profile.role=manager）管全校并可 Excel 导入 |

- 每个学生最多绑定 2 位家长（家长1/家长2 姓名字段）。
- 学生免密登录适合校内共享设备；学生首页有醒目的“退出 / 切换学生”按钮。

## 测验规则

- 60% 过关；每本书最多 **3 次提交机会**（失败后可重考 2 次），未提交不占次数。
- 重考会打乱题目顺序，且每次都会重排选项位置（防背答案）。
- 首次过关即累计词数，同一本书只记一次。
- 保留老师手工补录入口（工作台“登记阅读过关”）。

## 排行榜

`/ranks/` 一页同时展示 **词数榜 / 时长榜 / 本数榜**，支持 **班级 / 年级 / 全校** 三级与 **周 / 月 / 学期 / 累计** 四种周期；所有登录角色可见，学生/家长本人行高亮。学期定义：9 月 1 日–次年 1 月 31 日、2 月 1 日–8 月 31 日（可在 `config/settings.py` 的 `TERM_BOUNDARIES` 修改）。

## 图书馆

`/library/`：全校图书馆，按难度分类（分级读物 / 桥梁书 / 初章书 / 中章书 / 高章书）、标注兰斯值（Lexile）、书名搜索；老师与管理者可添加/编辑书籍。

## 管理者 Excel 批量导入

`/manage/import/`（仅管理者）。页内可下载模板，列顺序：

`年级 | 班级名称 | 教师用户名 | 学生姓名 | 英文名 | 邮箱 | 初始密码 | 家长1 | 家长2`

- 年级为 1–12 数字；教师用户名必须已存在且为老师账号；班级不存在时自动创建。
- 邮箱全局唯一；提供邮箱必须同时提供初始密码（家长登录凭证）。
- 导入为“全有或全无”：任何一行有错整批不生效，并按行号报错。

## 中英文切换

页面右上角语言下拉可切换简体中文 / English（对全部界面生效；书名与测验题保持英文）。修改 `locale/*/LC_MESSAGES/django.po` 后运行 `.venv\Scripts\python.exe scripts\po2mo.py` 重新编译（无需安装 gettext），再运行 `.venv\Scripts\python.exe scripts\check_i18n.py` 核对目录（改完 .po 需重启 runserver 才生效）。

手写目录有两条容易静默失效的规则，`check_i18n.py` 会按运行时实际查找的 msgid 校验：

- 模板里字面的 `%` 在查表前会被加倍，所以 `{% trans "60% 过关" %}` 对应的 msgid 要写成 `60%%`。
- `{% blocktrans %}` 的占位符在 msgid 中是 `%(name)s`，不是 `{{ name }}`；其 msgstr 会被 `%` 格式化，字面 `%` 同样要写成 `%%`。

## 其他

- 班级阅读目标：老师在工作台设置目标词数与截止日期，学生/家长端可见进度条。
- Excel 导出：工作台“导出 Excel”。
- 部署前需硬化（不在 P1 范围）：`DEBUG=False`、`STATIC_ROOT`、`AUTH_PASSWORD_VALIDATORS`、学生共享设备的会话时长。

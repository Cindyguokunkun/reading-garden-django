# 阅见 · Django 本地版

仓库地址：https://github.com/Cindyguokunkun/reading-garden-django

标准 Django Templates 项目。Django 同时负责页面、登录、业务逻辑和 SQLite 数据库；页面交互不依赖 React。

## 初次安装

双击 `setup.bat`。完成后双击 `start.bat`，打开 http://127.0.0.1:8000/。

- 初始用户名：`teacher`
- 初始密码：`reading123`（首次登录后请在 `/admin/` 修改）
- 数据库文件：`db.sqlite3`

手机与电脑连接同一 Wi-Fi 后，在手机访问 `http://电脑局域网IP:8000/`。Windows 防火墙首次询问时允许“专用网络”。

## 四种角色与登录入口（P1）

登录枢纽 `/login/` 提供三个入口：

| 角色 | 入口 | 登录方式 | 能做什么 |
| --- | --- | --- | --- |
| 学生 | `/student/login/` | 免密：选班级 → 点自己名字 | 自助先读后测、看个人记录与排行榜 |
| 家长 | `/parent/login/` | 孩子的邮箱 + 密码（由管理者导入时发放） | 只读查看孩子阅读记录、目标进度、排行榜 |
| 老师 / 管理者 | `/login/staff/` | 账号密码 | 老师管本班；管理者（superuser 或 Profile.role=manager）管全校并可 Excel 导入 |

- 每个学生最多绑定 2 位家长（家长1/家长2 姓名字段）。
- 学生免密登录适合校内共享设备；学生首页有醒目的“退出 / 切换学生”按钮。

## 测验规则

- 60% 过关；每本书最多 **3 次提交机会**（失败后可重考 2 次），未提交不占次数。
- 重考会打乱题目顺序，且每次都会重排选项位置（防背答案）。
- 首次过关即累计词数，同一本书只记一次。
- 保留老师手工补录入口（工作台“登记阅读过关”）。
- 交卷后可回看本次作答（“查看答案”），口径按身份分三档：
  - **学生**：只能回看自己**已通过**的答卷——没过就回看等于背下答案重考。
  - **家长**：在家长首页的“测评记录”里打开自己孩子的答卷；**已通过的能看逐题答案**，未通过的只显示分数、提交时间与剩余重考次数，不显示题目与答案。家长账号只绑定登录时那一个孩子，改网址看别的学生一律 403。
  - **老师 / 管理者**：可看权限范围内（老师=本班，管理者=全校）学生的全部已提交答卷，含未通过的，用于讲评。
- 未登录访问回看页会跳到登录页。没有题目快照的历史答卷显示“该历史答卷无法逐题回看”，**不会拿当前题库伪造当时的题目**。

## 排行榜

`/ranks/` 一页同时展示 **词数榜 / 时长榜 / 本数榜**，支持 **班级 / 年级 / 全校** 三级与 **周 / 月 / 学期 / 累计** 四种周期；所有登录角色可见，学生/家长本人行高亮。学期定义：9 月 1 日–次年 1 月 31 日、2 月 1 日–8 月 31 日（可在 `config/settings.py` 的 `TERM_BOUNDARIES` 修改）。

## 阅读等级与百万星光榜

学生的**累计阅读词数**（首次通过测验即累计、全时段汇总）会自动换算成一个阅读等级称号；称号只按词数实时算出、**不存数据库**，永远不会和阅读记录对不上：

| 累计词数 | 等级称号（英文 / 中文） |
| --- | --- |
| 1 万 | Bronze Reader / 青铜读者 |
| 10 万 | Silver Reader / 白银读者 |
| 50 万 | Gold Reader / 黄金读者 |
| 100 万 | Platinum Reader / 铂金读者 |
| 500 万 | Diamond Reader / 钻石读者 |
| 1000 万 | Legendary Reader / 传奇读者 |

- 学生与家长首页显示当前等级徽章、升级进度条与「距下一级还差 N 词」，每级徽章有独立配色（青铜→白银→黄金→铂金→钻石→传奇）。
- `/ranks/` 顶部新增**百万星光榜**：全校累计 ≥ 100 万词（铂金及以上）自动上榜，按累计词数排名并标注等级；不受排行榜维度/周期选择影响，无人达标时自动隐藏。
- 阈值、称号与百万榜门槛集中在 `reading/stats.py` 顶部的 `READING_LEVELS` 与 `MILLION_CLUB_WORDS`，改完 runserver 自动重载；改中文称号需同步 `locale/zh_Hans/LC_MESSAGES/django.po` 后重新编译（见「中英文切换」）。

## 图书馆

`/library/`：全校图书馆，按难度分类（分级读物 / 桥梁书 / 初章书 / 中章书 / 高章书）、标注难度值（ATOS，未填时回退显示手填的兰斯值）、书名搜索；老师与管理者可添加/编辑书籍。列表是带封面的卡片（手机上一本书一行，封面在左），卡片上直接显示难度、词数、有无测验，学生还会看到自己的「已测 xx%」或「想读」标记与加入/移出书架按钮。

点书名进 `/library/<pk>/` 书籍详情页：封面、书名、作者、难度、词数、分类、内容简介、同系列其他册，以及按身份出现的操作（学生/家长：加入书架、开始测评；老师/管理者：编辑）。没有测验的书，“开始测评”显示为不可点的「暂无测验」。

书籍字段新增 **作者** 与 **封面图片网址**：作者可手填，也会在 AR BookFinder 选中候选时自动填（仅在原值为空时）；封面只存远程图片网址，不下载、不占本地空间——远程图挂了页面就显示破图，此时把网址清空即回到首字母占位图。

**书名 + 作者**在四处一并显示，便于区分同名书：图书馆卡片、书籍详情页、测验开始页的书名下拉、答题结果页。

## 我的书架

`/shelf/`（学生与家长）：把想读的书加进来，读过的自动显示最高过关分。列表卡片来自图书馆或书籍详情页的“加入书架”按钮，随时可移出。

- 状态**不存字段**：「已测 xx%」与「想读」每次由本人的过关记录实时算出，永远不会和成绩对不上。
- 家长看到的是孩子的书架（导航栏写作“孩子书架”），与学生本人一致，只读不改。

## 查难度与 AI 出题（P2）

`/library/add/` 与每本书的“编辑”页提供四个工具按钮，全程在表单内完成，不写代码、不跑脚本。**任何自动查询都只填表单，点“保存”才写数据库。**

**自动查询书籍信息**：输入书名后点一次，同时查 AR BookFinder（标准书名、作者、ATOS、词数、内容简介）与封面服务，两路各自独立降级——AR BookFinder 没查到时，封面候选照样列出来。

- **同名多版本不会自动取第一条**：候选表列出封面缩略图、书名、作者、AR 编号、IL、BL、AR 分，由老师点“选定并填入”决定用哪一条。
- 选中后自动填入**作者**、ATOS、词数与内容简介；难度分类、系列、级别说明、封面只在原值为空时填，**书名永不覆盖**。
- **作者已手填过就不静默改写**：查询到的作者与已填的不同时，表单里并列「保留现有「…」／使用查询到的「…」」两个单选由老师定（与词数冲突同一套机制），选完点保存才生效。
- **多位作者完整保留顺序**（如 `Roland, Timothy & Smith, Jane`），不会只留第一位。
- 查不到作者不影响保存：作者一栏始终可手填，也可留空。
- AR BookFinder 不提供兰斯值，`兰斯值` 一栏始终手填。

**只查找封面**：只跑封面服务（最多 8 条，先 Open Library，失败或查不到再退 Google Books，**都不需要 API key**），适合 AR BookFinder 不收录、或难度已填只想补封面的书。点“选定此封面”只把网址填进表单的 `封面图片网址`，要点“保存”才真正入库；填进来的网址限定在几个封面域名内，改不动成别的地址。Open Library 按书名模糊匹配，**同名的不同版本/改编本会认错**，选定前请看一眼缩略图。

难度分类按 ATOS 自动建议（档位可在 `config/settings.py` 的 `ATOS_BANDS` 调整）：

| ATOS | 难度分类 |
| --- | --- |
| < 1.5 | 分级读物 |
| 1.5 – 2.4 | 桥梁书 |
| 2.5 – 3.4 | 初章书 |
| 3.5 – 4.9 | 中章书 |
| ≥ 5.0 | 高章书 |

**AI 生成测验题**：需要先配置 `.env`（见下）。素材有两个通道：上传 `.txt` 或直接粘贴正文；都没填时回退使用内容简介，三者皆空则拒绝生成——这是防止模型凭记忆编造情节（改编本与原著常常不同）。**素材要和书名对得上**：书名也会作为提示送给模型，两者不符时正确答案仍只出自素材，但干扰项里会混进书名中的词。一次生成约 40–80 秒，期间请勿离开页面或重复点击；**生成成功后也别按 F5 刷新**——浏览器会问“是否重新提交表单”，确认就会再花一次钱重新生成（防重复机制只挡同时进行的请求）。返回的题目**不会直接入库**：老师要在表单里逐题预览、修改、勾选“删除此题”，点“保存”才写入；任何一题不合格（选项少于 2 个、答案越界、选项重复等）则整批不保存，并按题号报错。

**编辑现有测验题**：旧题库可以在这里逐题修正（含早期只有 1 个选项、学生必得满分的废题）。

### 配置 `.env`

复制 `.env.example` 为 `.env` 后填写，改完必须重启 `runserver`（`.env` 只在启动时读取一次；真实环境变量优先于文件）。`.env` 已被 `.gitignore` 忽略，**不要把密钥贴进聊天、issue 或提交到仓库**——它只出现在请求的 `Authorization` 头里，不会写进日志、页面提示或异常信息。

出题走任何 OpenAI 兼容的 `/chat/completions` 端点：`QUIZGEN_BASE_URL`、`QUIZGEN_API_KEY`、`QUIZGEN_MODEL` 三项都填了才渲染出题按钮，否则页面只显示一行配置提示（优雅降级，其余功能不受影响）。`QUIZGEN_QUESTIONS` 默认 10 题；端点不支持 `response_format=json_object` 时改 `QUIZGEN_JSON_MODE=0`。抓取相关的 `ARF_PROXY` 默认指向本机 Clash（`http://127.0.0.1:7897`），留空则直连。

封面抓取另有一组：`COVERS_PROXY`（默认同 `ARF_PROXY`，留空直连）、`COVERS_TIMEOUT`（超时秒数，默认 10）、`COVERS_THROTTLE`（两次请求最小间隔，默认 1.0 秒）。两路都不需要 key；抓取失败只在页面上提示一句，不影响保存书籍。**已知情况**：国内网络下 Google Books 长期返回 HTTP 429（配额限制，与本机配置无关），所以实际可用的通常只有 Open Library 一路。

### 两点已知限制

- **覆盖率**：本库 404 本书里 309 本是「典范英语」，AR BookFinder 不收录这套中国出版物，自动查询只对英文原版书有效；典范英语请走“上传文本 + AI 出题”。
- **使用条款**：自动访问 AR BookFinder 属灰区。程序用诚实的 UA、请求间隔 ≥ 1 秒（`ARF_THROTTLE`）、且只做单本按需查询、不做批量回填；万一被封，所有字段仍可手工填写。

## 管理者 Excel 批量导入

`/manage/import/`（仅管理者）。页内可下载模板，列顺序：

`年级 | 班级名称 | 教师用户名 | 学生姓名 | 英文名 | 邮箱 | 初始密码 | 家长1 | 家长2`

- 年级为 1–12 数字；教师用户名必须已存在且为老师账号；班级不存在时自动创建。
- 邮箱全局唯一；提供邮箱必须同时提供初始密码（家长登录凭证）。
- 导入为“全有或全无”：任何一行有错整批不生效，并按行号报错。

## 中英文切换

页面右上角语言下拉可切换简体中文 / English（对全部界面生效；书名与测验题保持英文）。修改 `locale/*/LC_MESSAGES/django.po` 后运行 `.venv\Scripts\python.exe scripts\po2mo.py` 重新编译（无需安装 gettext），再运行 `.venv\Scripts\python.exe scripts\check_i18n.py` 核对目录（改完 .po 需重启 runserver 才生效）。

手写目录有两条容易静默失效的规则，`check_i18n.py` 会按运行时实际查找的 msgid 校验：

- 模板里字面的 `%` 在查表前会被加倍，所以 `{% trans "60% 过关" %}` 对应的 msgid 要写成 `60%%`。
- `{% blocktrans %}` 的占位符在 msgid 中是 `%(name)s`，不是 `{{ name }}`；其 msgstr 会被 `%` 格式化，字面 `%` 同样要写成 `%%`。
